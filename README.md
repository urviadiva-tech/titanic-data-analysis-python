# 🚢 Titanic Data Analysis using Python

## 📊 Project Overview

This project is a basic data analysis assignment performed on the Titanic dataset.

It includes data extraction, cleaning, statistical analysis, and visualization using Python libraries.

---

## ⚙️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Google Colab

---

## 🔍 Work Done

* Loaded dataset using `pandas.read_csv()`
* Checked and handled missing values
* Removed duplicate records
* Performed statistical analysis (mean, median, mode, variance, etc.)
* Created multiple visualizations using Matplotlib and Seaborn

---

## 📈 Visualizations Included

* Bar Plot
* Histogram
* Scatter Plot
* Pie Chart
* Box Plot
* Heatmap

---

##  How to Run

1. Open the notebook in Google Colab or Jupyter Notebook
2. Run all cells
